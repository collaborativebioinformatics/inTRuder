# Git commit / PR rules

- Never add a co-author line (e.g. `Co-Authored-By: Claude ...`) to commits.
- Never include a Claude session link (`Claude-Session: ...`) or any Claude/Anthropic attribution in commits, PR descriptions, PR comments, or anywhere else.
- Commit messages must be SHORT and targeted: a single concise summary line describing the change. Avoid multi-paragraph bodies, bullet lists of every file touched, or restating the diff.
