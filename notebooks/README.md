# Notebooks

- [`novel_tr_results.ipynb`](novel_tr_results.ipynb) — what the novelty screen and the
  STRchive comparison found on the 500-insertion sample, and what the numbers do not support.
- [`compression-method.ipynb`](compression-method.ipynb) — working out the compressibility
  proxy for repetitiveness that became `uv run compression`.
- [`comp_histograms.ipynb`](comp_histograms.ipynb) — the ratio distributions those thresholds
  came from. See [docs/scripts/annotate_compression.md](../docs/scripts/annotate_compression.md).

Exploratory and analysis notebooks — Jupyter (`.ipynb`) for Python and R Markdown /
Quarto (`.Rmd` / `.qmd`) for R. Use these for interactive exploration and reporting;
promote reusable code into `src/python` or `src/R`.

Run Python notebooks in the uv environment (`uv run jupyter lab`) and R notebooks
with the renv environment active.
